# jsonrepair-rs 0.2.5

This release adds opt-in schema-guided correction for common LLM tool argument
mismatches. With the `serde` feature, `jsonrepair_value_with_schema` first
repairs JSON syntax, then converts numeric and boolean strings, corrects an
unambiguous ASCII case-insensitive string enum match, and wraps a non-null
singleton value when the schema expects an array. Corrections also apply
through nested `properties` and array `items`.

The helper leaves ambiguous or unsupported values unchanged and does not
validate the full JSON Schema. Validate its result before executing a tool
call.

This release is source-compatible with 0.2.4. Existing APIs, error types, and
default repair behavior are unchanged.
