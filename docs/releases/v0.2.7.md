# jsonrepair-rs 0.2.7

Maintenance release — 2026-11-16.

## Fixes since 0.2.6

- Escaped CRLF inside quoted strings is consumed as one line continuation,
  instead of leaving the LF in the repaired value. Existing LF/CR behavior,
  adjacent literal line endings and escaped backslashes remain covered.
- CLI `--output=...` preserves native path units. Unix arguments retain raw
  non-UTF-8 bytes; Windows arguments retain UTF-16 units, including unpaired
  surrogates. Empty, Unicode and equals-containing arguments follow the same
  parsing rules as before.
- Error coordinate calculation iterates the same character prefix directly to
  satisfy Rust 1.100 Clippy. It still counts Unicode scalar values, resets the
  column after LF, and stops at the input length when a position exceeds it.

The CRLF and path fixes were already merged in `3f6d645` and `41dfbb3`. This
candidate adds release metadata, validation and the equivalent error-coordinate
iteration cleanup, not another parser feature.

## Compatibility and scope

Public APIs, error types, dependency requirements and feature flags are unchanged.
Default repair policies and the independent comment-preservation/escape-decoding
options keep their existing contracts. The core library and CLI retain Rust 1.70
support; optional dependencies keep their own compiler requirements.

Reader/writer helpers remain fully buffered and wait for EOF. This release does
not add incremental JSON parsing, full JSON Schema validation, Python/Node
bindings or a downstream application migration.

## Candidate verification

The [maintenance readiness record](../reports/maintenance-0.2.7-20261116.md)
records source provenance, commands, package inspection and actual results.
macOS Unix-byte parser tests do not prove Linux filesystem behavior or Windows
UTF-16 execution. Native platform results must be recorded separately before
claiming cross-platform release acceptance.

The reviewed candidate passed Linux, Windows and minimum-Rust CI. The final
release includes the subsequent locked-dependency security update, whose main
branch CI also passed. Registry publication and docs.rs availability are verified
separately during release execution.
