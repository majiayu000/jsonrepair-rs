# jsonrepair-rs 0.2.4

This maintenance release updates compatibility checks and CLI documentation.

- CI verifies that the core library and CLI compile with Rust 1.70. The README
  clarifies the Rust-version boundary for the optional `serde` feature.
- The CLI shell example now returns the command's original exit code after
  reporting an error, so scripts can distinguish usage errors from repair or
  IO errors.

There are no runtime behavior, public API, or error-type changes from 0.2.3.
